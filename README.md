# Chat App

A simple chat application with WhatsApp-style UI, mock backend, and session history.

## Features

- WhatsApp-inspired dark theme UI
- Mock backend that echoes messages back
- Session history stored in browser localStorage
- Responsive design
- Smooth animations
- Clear history option

## How to Use

1. Open `index.html` in a web browser
2. Type a message in the input field
3. Press Enter or click the send button
4. The bot will echo your message back
5. Chat history is automatically saved and persists across sessions
6. Click "Clear History" to delete all messages

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage for persistence

## Structure

- `index.html` - Main HTML structure
- `style.css` - WhatsApp-style CSS styling
- `app.js` - Chat logic with mock backend and session history
